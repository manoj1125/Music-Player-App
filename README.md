🎵 Web Music Player App

A sleek, responsive, and interactive web-based Music Player application built using native web technologies—HTML5, CSS3, and modern JavaScript (ES6+).

✨ Features

Interactive Playback Controls: Play, pause, skip forward, and play previous tracks seamlessly.

Dynamic Track Progress: Real-time progress bar tracking with interactive click-to-seek functionality.

Playlist & Album Art: Displays current track details including title, artist, and album cover art.

Responsive UI/UX: Clean, modern design optimized for desktop and mobile devices.

Volume & Mute Control: Adjust audio volume smoothly on the fly.

🛠️ Built With

 HTML5: Semantic markup for structured audio player layout.

 CSS3: Custom styling, flexbox/grid layout, smooth transitions, and glassmorphic/modern UI elements.

 JavaScript (ES6+): DOM manipulation, HTML5 Audio API handling, dynamic audio event listeners.
